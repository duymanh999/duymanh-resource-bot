TỆP MẪU — KHO TÀI NGUYÊN

Đây chỉ là tệp hướng dẫn mẫu để kiểm tra website/bot.
Hãy thay bằng tệp do bạn sở hữu hoặc được phép chia sẻ.

Cách thêm tệp:
1. Đưa tệp vào thư mục resources/.
2. Mở server.js và thêm một mục vào mảng RESOURCES, ví dụ:
   {
     id: "guide-pdf",
     title: "Tài liệu hướng dẫn",
     filename: "guide.pdf",
     description: "Tài liệu do tôi tạo."
   }
3. Lưu, đẩy thay đổi lên GitHub và triển khai lại dịch vụ.
4. Dùng /files trong Telegram để kiểm tra.

Không thêm mật khẩu, token bot hoặc dữ liệu riêng tư vào tệp công khai.
